# Neon Champions Game Design

Private production-facing design repo for Neon Champions.

This repository is the source of truth for approved game design, gates, production planning, and later implementation handoff. It is intentionally separate from the lore-first worldbuilding wiki.

## Relationship to the worldbuilding wiki

- Worldbuilding wiki: exploratory lore, canon, rumors, contradictions, trope studies, design bridges.
- Game design repo: approved production-facing design, GDDs, gates, epics, stories, prototypes, playtests.

Worldbuilding ideas enter this repo only through approved lore imports or design bridges.

## Operating rule

No implementation from chat memory. Agents may implement only from approved GDDs, accepted ADR/control-manifest rules, and READY stories.
