# Lore Import Policy

## Rule

The worldbuilding wiki is not directly implementation-authoritative.

A lore element becomes game-authoritative only when summarized or imported here with approval status.

## Import levels

1. Reference
   - Useful context only. Not a production requirement.

2. Approved game-facing lore
   - Stable enough to guide naming, factions, systems, UI, or content.

3. GDD requirement
   - Translated into concrete mechanics/rules/acceptance criteria.

## Required import fields

- Source world wiki path or URL.
- Summary of the relevant lore.
- What is approved for game use.
- What remains speculative or excluded.
- Affected GDDs.
- Approval status.

## Never import directly

- Raw brainstorms as requirements.
- Rumors as facts unless the game design uses them as rumors.
- Rejected ideas.
- Contradictions without classification.
